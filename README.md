# Allvideo

A romantic 2.5D story-platformer about love, patience, light, and understanding.

## Project status

A Vite + React + Three.js story-platformer. Chapters 1–6 are selectable from the game interface.

## Personal photos and privacy

Chapter 6, **Memory Lane**, reads scene titles, captions, dates, and photo paths from `src/story/personal.config.js`. Add personal photos under `public/personal/` and reference them with public paths such as `/personal/our-photo.webp`.

**Photos stay in `/public/personal`, and you decide what to commit.** The default configuration contains no personal photo paths or real personal details. Missing or unavailable photos are replaced with illustrated placeholders. Review your changes before committing; do not add private photos to version control unless you explicitly choose to.

See `AGENTS.md`, `CLAUDE.md`, and `docs/ASSET_TODO.md` for project guidance and asset notes.
